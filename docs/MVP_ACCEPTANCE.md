# MVP 验收标准

更新日期：2026-09-11

## A. 工作区盘点与索引

- [ ] 打开一个现有目录后，在用户确认任何变更前不修改、移动或复制其中的文件。
- [ ] 总览准确显示 Markdown 文件、目录、字数、资源、Frontmatter、标签和链接数量。
- [ ] 支持文件名、全文、目录、Frontmatter、标签和问题类型的组合筛选。
- [ ] 新增、修改、重命名和删除文件后只增量更新相关索引。
- [ ] 新文件、外部修改、索引异常、低置信度和待复查项目进入统一 Inbox，处理完成后可归零。
- [ ] 删除应用索引后，原文件夹仍完整可用；重新扫描可以重建总览。
- [ ] 10,000 个普通 Markdown 文件的基准资料库可以完成扫描，扫描期间编辑器仍可响应。
- [ ] 无 AI 配置、模型离线或额度不足时，盘点、搜索和确定性检查仍可使用。

## B. 分类与批量治理

- [ ] 用户可以创建手动规则和虚拟集合，且默认不修改文件或目录。
- [ ] AI 可基于标题、路径、现有元数据和有限摘要提出分类树与逐文件分类。
- [ ] 每个 AI 分类显示类别、依据、来源文件、置信度和模型；低置信度进入人工队列。
- [ ] 用户可以修改类别、提供正反例，并只重新分析受影响文件。
- [ ] 用户可以保存已确认样本作为分类 Golden Set；更换模型、提示词或分类树前能先运行回归比较。
- [ ] 分类体系具有版本号，可比较覆盖率、冲突、未判断数量和迁移影响，并能回退虚拟分类结果。
- [ ] 分类结果可选写入 YAML Frontmatter；写入前展示逐文件最小 diff。
- [ ] 批量补字段、改标签、移动或重命名必须先生成 dry-run 计划。
- [ ] 计划展示影响文件、引用、资源、冲突和预计模型发送量。
- [ ] 批量任务部分失败时能明确区分成功、失败、跳过和冲突文件。
- [ ] 执行后自动复查索引、链接和 schema，并能回滚本次文件变更。
- [ ] AI 不得直接执行移动、重命名、覆盖、归档或删除。

## C. 文件完整性

- [ ] 打开并关闭文件但不编辑，文件 hash 不变。
- [ ] 打开后直接保存，除非用户执行格式化，否则文件字节不变。
- [ ] 修改一个段落，保存 diff 只包含用户实际修改的范围。
- [ ] 保留原文件编码和 LF/CRLF 换行形式。
- [ ] 崩溃重启后可以恢复未保存内容，同时不覆盖磁盘文件。

## D. 外部修改

- [ ] 外部程序修改当前文件后 1 秒内显示状态提示。
- [ ] 没有本地修改时可增量载入，并尽量保持光标和滚动位置。
- [ ] 存在本地修改时不自动覆盖，必须进入比较或合并流程。
- [ ] Git 切换分支、文件删除、重命名和快速连续写入都有明确结果。

## E. AI 与变更计划

- [ ] 默认只向模型发送用户选择的内容及最小必要上下文。
- [ ] AI 不能直接调用文件保存。
- [ ] 每个修改都以新增/删除 diff 展示。
- [ ] 用户可以逐块接受和拒绝。
- [ ] 接受后的修改可以通过普通撤销恢复。
- [ ] 文档基准变化后，旧 patch 不得静默应用。
- [ ] AI 请求失败时原文不发生变化，并给出可重试异常结果。
- [ ] 分类、重复、矛盾和过期类 AI 结论必须包含来源文件、基准 hash、引用片段和不确定性；没有证据的结论不能进入批量计划。
- [ ] 供应商预设、自定义 OpenAI-compatible 接入点和本地模型都使用同一套审阅流程。
- [ ] 不支持严格 JSON、工具调用、模型列表或 embedding 的接入点能明确降级，不影响基础功能。
- [ ] 连接测试分别报告地址、鉴权、模型、流式输出和结果解析状态。

## F. Markdown 与预览

- [ ] 通过 CommonMark 官方规范测试集。
- [ ] GFM 表格、任务列表、删除线和自动链接行为明确。
- [ ] 预览不会重新序列化或修改源码。
- [ ] 原始 HTML 默认经过安全过滤。
- [ ] 公式或 Mermaid 渲染失败时显示原代码和错误，不阻塞编辑。
- [ ] YAML Frontmatter、脚注、公式、Mermaid 和警告块均可选择启用，未知语法不被擅自转换。
- [ ] 非法或重复 Frontmatter 字段只报告问题，不静默重写整个 Frontmatter。

## G. 编辑体验

- [ ] 中文输入法组合输入不产生重复字符或异常撤销。
- [ ] 查找替换、撤销重做、多光标和快捷键行为稳定。
- [ ] AI patch 和外部增量更新后尽量保留光标、选区及滚动位置。
- [ ] 5 MB Markdown 文件仍能输入、滚动和搜索；预览可降级或延迟。
- [ ] 表格辅助编辑只修改目标表格，未触及的文档字节不变。
- [ ] 阅读、纯编辑、编辑＋预览三种模式可以保留当前文档位置。

## H. 链接与资产管理

- [ ] 粘贴图片使用可配置的相对资源目录。
- [ ] 能识别缺失图片、孤立资源和重复文件。
- [ ] 重命名资源时先展示将被修改的引用。
- [ ] 路径修改以可撤销 patch 执行。
- [ ] 能识别 Markdown 链接、标题锚点和启用后的 WikiLink，并区分缺失、歧义和外部链接。
- [ ] 文件移动或重命名时先列出所有将更新和无法安全更新的引用。

## I. 隐私与安全

- [ ] 未启用 AI 时不上传文档内容。
- [ ] 调用 AI 前显示供应商、模型和发送范围。
- [ ] API Key 不写入项目文件或普通日志。
- [ ] API Key 存入系统安全凭据；渲染进程无法读取明文 Key。
- [ ] 支持按目录和 glob 永久排除 AI 发送范围。
- [ ] Markdown XSS 测试样本不能执行脚本、事件属性或危险 URL。
- [ ] 日志默认不记录正文和完整提示词。
- [ ] 审计记录能区分人工、AI、规则和外部程序变更，并记录模型、来源范围和基准 hash。
- [ ] 若提供 CLI、插件或 Agent 实验接口，默认只读且无法绕过 Governance Plan 直接写文件。

## MVP 完成定义

只有当 A–F 全部通过，G–I 没有高风险失败时，才可以把版本称为可体验 MVP。页面能打开、索引数字能显示、预览能渲染或 AI 能返回分类文字，都不能单独作为完成证据；必须完成一次“盘点→分类→dry-run→应用→复查→回滚”的真实资料库闭环。
