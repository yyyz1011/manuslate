# PatchMark 实现状态

更新日期：2026-09-11  
版本：0.2.0

## 本轮交付

第一条纵向闭环已经可以运行：

1. 默认打开一套内置示例资料库，便于不授予目录权限时直接评审产品。
2. 在支持 File System Access API 的浏览器中选择一个本地目录。
3. 递归读取 Markdown，扫描过程不写入目录。
4. 解析标题、Frontmatter、标签、状态、结构大纲、链接、字数和更新时间。
5. 检查缺少标题、Frontmatter 错误、失效链接、缺失资源、孤立文档和重复正文。
6. 在总览、智能集合、搜索筛选和治理收件箱中查看问题。
7. 使用 CodeMirror 6 编辑，并在编辑、分屏和阅读模式间切换。
8. 保存前展示逐行差异；写入前验证磁盘版本哈希，拒绝覆盖外部修改。
9. 配置 OpenAI-compatible、Ollama 或 LM Studio 接入点，并在不发送文档的前提下做连接探测。
10. 通过 Tauri 2 生成 macOS 桌面应用，目录访问和保存由 Rust 命令执行。
11. 在本地 SQLite 中建立文档元数据与 FTS5 全文索引，使用 WAL 日志模式。
12. 在设置页展示索引真实路径、体积、文档数，并支持重建或仅清空索引。

## 已验证

- `npm test`：6 项分析与回归测试通过。
- `npm run build`：TypeScript 检查和 Vite 生产构建通过。
- 浏览器人工流程：总览 → 打开文档 → 编辑 → 差异检查 → 示例保存通过。
- 浏览器控制台：没有 error 或 warning。
- 首屏主代码约 114 KB gzip；Markdown 预览和 CodeMirror 按需加载。
- `cargo test`：3 项 Rust 测试通过，包括随应用编译的 SQLite FTS5 验证。
- `cargo check` 与 Tauri release 构建通过，生成可双击的 `PatchMark.app`。
- 桌面集成流程：选择目录 → 3 文件只读盘点 → SQLite 入库 → FTS5 查询 → 差异确认 → 原子保存 → 索引同步通过。

## 仍未宣称完成

- macOS 开发包尚未签名和公证；Windows/Linux 包尚未构建验证。
- 桌面扫描已转到 Rust 后端，但尚未完成 10,000 文件性能验收和文件系统监听。
- SQLite 已落地，前端搜索暂时仍使用内存过滤，下一步切换为 FTS5 查询和增量结果流。
- AI 目前只实现接入点配置与能力探测，没有发送正文或生成治理建议。
- 还没有批量 Frontmatter 补丁、移动/重命名事务、备份与回滚。
- 许可证尚未最终选择，因此不能把当前本地代码描述为已经正式发布的开源版本。
